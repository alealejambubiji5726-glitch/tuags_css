Langkah - Langkah Collab GitHub

  1. Buka GitHub
  2. Masuk repository
  3. Masuk setting
  4. Masuk collaborators
  5. verifikasi kode yang masuk ke email kalian(email akun GitHub kalian)
  6. klik add people
  7. masukkan username yang ingin kalian tambahkan
  8. buka akun gmail(email yang buat login github) buat terima ajakan
  9. konfirmasi
  10. buka laragon
  11. Buka terminal
  12. pastikan difolder www
  13. clone kan project teman kalian/yang di collabkan
  14. ketik [Git clone (URL repository dari project teman kalian)] lalu enter
  15. Cara Menyalin kode URL:
    • buka repository yang akan di clone
    • klik code
    • salin link url
  16. masuk folder yang habis di clone
  17. jalankan perintah (cd nama_folder_clone)
  18. pastikan di samping nama folder WWW sudah tterdapat nama folder clone nya
  19. ketik perintah (code .) untuk masuk vscode secara otomatis
